# una expresión regular por línea.
# las líneas vacías y las que empiezan con # se ignoran.
#
# la cadena w se pasa aparte con -w, o se escribe por teclado cuando el
# programa la pide. de forma opcional, después de un ';' se pueden listar
# cadenas de prueba separadas por coma (una cadena vacía entre comas, o al
# final, significa la cadena vacía).

# expresión del examen (reglas de gramática tipo BNF: "NOMBRE ::= producción").
# ojo: el '*' se perdió al copiar/pegar desde el chat (markdown lo interpreta
# como negrita); esta es la versión con los '*' restituidos.
[A-Z][A-Za-z0-9_]*\s*::?=\s*([A-Za-z0-9_|'"\s\[\](){}*+?\\-]|\|)+;S ::= A B | C,EXPR ::= term '+' term | term,123VAR = value
